# Ally Drones website

The website for Ally Drones: drone pilot training, aerial mapping and building inspection in Accra, Ghana.

It's a single static page (`index.html` and `img/`), served by GitHub Pages from the `main` branch root. There's no build step.

Interactive pieces:

- A drone that follows the cursor on desktop. On phones it flies to wherever you touch, then returns to its corner.
- A live camera-style readout (altitude, speed, heading, coordinates) and an altimeter that tracks the scroll.
- A sample mapping survey animation, a roof-inspection magnifier with a simulated thermal view, and a ring-run flight simulator.
